# BD'event — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Web app du BDE MIAGE Nice qui, pour chaque événement, crée le dossier Drive, copie le Sheet d'organisation et la déclaration pré-remplie, crée le dossier Canva, génère la to-do administrative et gère la to-do de l'événement (exportable en Google Sheet).

**Architecture:** Client React + Vite (JS/JSX, comme cafeteria-manager) publié sur GitHub Pages ; Supabase pour l'auth Google, la base Postgres (RLS) et les Edge Functions (Deno/TS) qui parlent à Google (compte de service, Drive partagé) et Canva (OAuth PKCE). La logique pure vit dans `supabase/functions/_shared/domain/` (JS sans dépendance), importée par les Edge Functions et par le client (alias Vite `@domain`), et testée avec Vitest.

**Tech Stack:** React 18.3, Vite 5.4, @supabase/supabase-js 2, Vitest 2, Supabase CLI (paquet npm `supabase`, en devDependency), pgTAP (`supabase test db`), Deno (Edge Functions), `npm:jose@5.9.6` (JWT du compte de service).

**Spec:** `docs/superpowers/specs/2026-11-06-bd-event-design.md`

## Global Constraints

- Domaine autorisé d'office : comptes dont l'email se termine par `@bdemiagenice.com` (comparaison insensible à la casse).
- Fuseau de toutes les dates affichées et calculées : `Europe/Paris`. Les Edge Functions tournent en UTC : aucun calcul ne dépend du fuseau du processus.
- Année scolaire : commence le 1er septembre ; format `AA-AA` (`26-27`).
- Chemin Drive : `<Drive partagé BDE MIAGE NICE> / <AA-AA> / Event / AAAA-MM-JJ – <Nom>` (tiret demi-cadratin `–` entouré d'espaces).
- Noms de fichiers : `Organisation – <Nom>`, `Déclaration – <Nom>` ; dossier Canva : même nom que le dossier Drive.
- Importances : 1 Très basse, 2 Basse, 3 Moyenne, 4 Haute, 5 Très haute. Statuts : `todo` À faire, `doing` En cours, `done` Fini.
- Étapes de création, dans cet ordre : `drive_folder`, `sheet`, `declaration`, `canva`, `admin_tasks`. États : `pending`, `done`, `failed`, `skipped`.
- Tous les appels Drive passent `supportsAllDrives=true`.
- Les fichiers de `_shared/domain/`, `_shared/google.js`, `_shared/canva.js`, `_shared/errors.js` et les `core.js` : JS ESM, imports relatifs avec extension `.js`, uniquement des API web (pas de `node:`, pas de `npm:`), pour tourner à la fois sous Deno et sous Vitest.
- Aucun secret ni jeton n'est renvoyé au client. Clé `service_role` uniquement dans les Edge Functions.
- Textes de l'interface en français. Design : MIAGE Étendu (tokens, `bundle.css`, polices, logo, Michel) ; jamais de valeur hexadécimale dans un composant, toujours un token.
- Messages d'erreur exacts (spec §6.5) :
  - `ERR_DRIVE` = « Le compte de service n'a pas accès au Drive partagé : ajoute-le comme Gestionnaire de contenu. »
  - `ERR_TEMPLATE` = « Modèle introuvable : vérifie le lien dans Admin. »
  - `ERR_CANVA_AUTH` = « Reconnecte Canva dans Admin. »

## Review Focus

1. **Nom d'événement avec apostrophe ou guillemet** (« Soirée d'intégration ») : la requête Drive de recherche de dossier doit échapper `'` et `\` ; le dossier est trouvé ou créé normalement. → test dans la tâche 8.
2. **Tâche dont le texte commence par `=`, `+`, `-` ou `@`** exportée vers le Sheet : elle doit apparaître comme texte, pas comme formule (`valueInputOption=RAW`). → tests dans les tâches 8 et 12.
3. **Événement en fin de soirée autour du 1er septembre ou d'un changement d'heure** : année scolaire, date du dossier et échéances calculées en heure de Paris, pas en UTC. → tests dans la tâche 2.
4. **Champs optionnels vides** (pas d'heure de fin, pas de description, participants vides) : les balises sont remplacées par une chaîne vide, jamais `null` ou `undefined` ; `0` participant reste `0`. → test dans la tâche 2.
5. **Reprise après échec ou double clic** : relancer une étape déjà `done` ne refait rien ; relancer `drive_folder` réutilise les dossiers existants au lieu d'en créer des doublons. → tests dans la tâche 9.
